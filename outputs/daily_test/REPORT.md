# 배포 웹 일상 이미지 보정 품질 테스트 (핵심 서브셋)

- **경로: 실제 배포 백엔드** `https://cvd-lens.onrender.com/infer` (프론트가 호출하는
  엔드포인트, `useCVDModel.ts`). 프론트와 동일 조건: 업로드 전 **2048px cap** + JPEG q92,
  서버가 letterbox 256 → per-type ONNX → delta 업샘플 → composite.
- 서브셋: **음식·피부·신호등/교통·자연** × 3타입(p/d/t) × 강도(0.6, 1.0) = **24 케이스**.
- 시뮬레이션: Brettel-1997(`cvdlens_v2.simulation`, method='brettel'). daltonize import 없음.
- 각 케이스: 원본 / 보정본 / sim(원본) / sim(보정본) 저장 + 몽타주. 코드 수정 없음(순수 테스트).
- 스크립트: `cvdlens_v2/daily_test.py` · 조사 #1~3 원인(`../artifact_analysis/REPORT.md`)을
  아티팩트 해석에 반영.

## 사전 등록 예상 (실행 전)

- **음식(빨간 토마토+초록 줄기):** p/d에서 빨강↔초록 대비가 sim view에서 개선(방향 HIT
  예상). 단 red 대면적이라 **#1 얼룩/과채도** 위험(강도 1.0). t는 거의 무변(빨강은
  tritan confusion 아님).
- **피부(인물+줄무늬 셔츠):** 핵심 체크포인트. p/d에서 피부가 **노랑/주황으로 이동**
  예상(skin_analysis: 피부 w≈0.73). 강도 0.6에서 완화. 줄무늬 흑백 셔츠는 무채색이라
  보존(선택성 HIT 예상). t는 피부(약간 노랑끼)도 confusion이라 이동 가능.
- **신호등/교통(노란 택시+회색 도시):** 회색 빌딩·도로 **보존**(선택성 HIT 예상). 노란
  택시는 p/d/t 모두 어느 정도 confusion → 이동. 신호등 색은 작아 효과 미미 예상.
- **자연(주황 단풍):** 주황은 red-green 축이라 p/d 큰 이동 예상 + **과채도/얼룩 위험**.
  t도 주황(노랑끼) confusion → 이동. 강도 1.0에서 형광/과채도 위험.

## 카테고리별 Hit/Miss

- **음식 — HIT(부분).** 예상대로 red 대면적에서 **#1 과보정 재현**: 토마토 protan ΔE
  p99=**41.55**(mean 6.96) — 국소적으로 매우 강한 이동. deutan 시뮬뷰에서 토마토↔줄기
  분리는 개선(방향 ○). t는 예상대로 약함. → #1 조사 결론이 실사에서 확인됨.
- **피부 — HIT.** 핵심 체크포인트 통과: 피부 왜곡이 **경미**(ΔE 2.0–2.5, sat +.01~.02),
  흑백 줄무늬 셔츠 완벽 보존(선택성 ○). skin_analysis(#피부톤 스레드)와 정합. 0.6에서
  ΔE 2.51→2.01로 완화.
- **교통 — HIT(최고 선택성).** 회색 빌딩·도로 보존(ΔE~1, p99~6). 저채도 일상장면 과보정
  없음 — 예상 정확히 일치. 데모 후보(선택성 시연).
- **자연 — HIT(+경고).** 실제 회복(CRR 1.14–1.22)이 가장 큰 카테고리이나, **과채도**가
  가장 심함(Δsat deutan **+0.089**). 예상한 "형광/과채도"가 수치로 확인. 0.6에서
  +0.089→+0.080(d), +0.053→+0.047(p)로 완화.

## 강도 0.6 vs 1.0
전 카테고리에서 0.6이 ΔE·Δsat를 일관되게 **~10–25% 감소**(예: 피부 p ΔE −20%, 자연 p
Δsat 0.053→0.047). 방향성/회복은 유지. **0.6 기본값(#4) 타당성 실사로 뒷받침.**

## 데모/발표 후보
1. **교통 protan/deutan** — 회색 도시 보존 + 신호 색 유지: 선택성 시연에 최적.
2. **자연 단풍 deutan @0.6** — 회복(CRR 1.13)은 살리고 과채도는 억제한 균형점.
3. **음식 토마토 deutan** — 시뮬뷰(sim) 나란히로 "토마토-줄기 분리 개선"을 직관적으로 시연.
